Best Hexagonal Block Puzzle Games (2026): Falling Blocks vs Drag-and-Drop

Disclosure. UltraHive is our game. Ripsaw LLC makes it and publishes this site. The other games are made by other people. Each entry uses only the facts named for that game. This page does not include star ratings, review counts, or download numbers. The order is not a ranking.

Hexagonal block puzzles split into two styles. A falling-block game, the Tetris-like kind, drops pieces and you rotate them before they lock. A drag-and-drop game is one where you place pieces on the board. This page lines the two styles up next to each other. A longer comparison, which quotes each official page, is on hexagonal games like Tetris.

Two styles

Falling blocks

Pieces drop into the board. You move the current piece and rotate it, and it locks when it lands. On a hexagon grid a turn is 60 degrees. UltraHive and HexaTetra are falling-block hex puzzles. Hextris is a rotate-the-hexagon arcade in the same broad family: blocks fall, and you turn the hexagon rather than a piece.

Drag-and-drop placement

You place pieces onto the board yourself. Hexadu, Hex FRVR, and Block! Hexa Puzzle are drag-and-drop hex puzzles. Hexadu also has a daily challenge and a timed mode, so drag-and-drop on this page is not the same thing as untimed play.

HexTetris: Hex Block Puzzle is included for the store facts below. This page does not state whether that game is falling-block or drag-and-drop.
