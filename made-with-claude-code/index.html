How it was built

Building a Hexagonal Puzzle Game With Claude Code

By David Kon, Ripsaw LLC

Most of the code for UltraHive was written with AI assistance (Claude Code). Game design, testing, and tuning are by David Kon / Ripsaw LLC. The game is a $2.99 hexagonal falling-block puzzle on iPhone and Android, with no ads and no in-app purchases.

What shipped, and when

  • February 24, 2026: the iOS app launched on the App Store.
  • July 23, 2026: version 1.6.0.
  • September 10, 2026: Android on Google Play. The Android app is fully offline.

It runs on iPhone (iOS 17+), iPad, Mac with Apple Silicon (macOS 14+), Apple Vision Pro, and Android. On iOS, Game Center is used for leaderboards only. The game plays offline on iOS. Family Sharing is available on Apple.

What the AI wrote, and what a person did

Most of the code was written with Claude Code. David Kon designed the game, tested it, and tuned it. That is the split this site states. It is the same credit on the home page and in the press kit.

The game itself is a honeycomb, not a square grid. Pieces drop on an 11-column board and rotate in 60-degree steps. You can hold one piece, and a ghost preview shows where it will land. Classic mode has 25 intensity levels and five power-ups. Hive Bits is 28 handcrafted puzzles. How to play.

What this page does not say

This site does not say how the art was made. It does not say the art is AI-generated, and it does not say a person drew it. It also does not describe the code, the engine, or the steps used to rotate a piece on the hex grid. Those details can be added later by David Kon.
